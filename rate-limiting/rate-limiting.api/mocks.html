Rate Limiting — Admin Console

Screen mocks for the rate-limiting module's admin surface. Every read is gated @RequiresAction('rate-limit.view') — an ops/security persona; a rejected, unauthenticated request has no tenant to scope by.

Why this console exists. A 429 used to vanish with no trace anywhere. If a public endpoint — a payment link, most concretely — is actually being hammered, nothing told you it was happening.
