Idempotency Keys — Admin Console

Screen mocks for the idempotency-key module's admin surface, each mapped to the endpoint that backs it. Every read is gated @RequiresAction('idempotency.view') — an ops/support persona, not a tenant-scoped one (see the module README).

Why this console exists. Two facts about a claim used to be invisible even querying the table directly: whether a claim was fresh or a reclaim of a possibly-still-running one, and whether a complete() call was silently dropped because its claim had already been reclaimed. The second one is unambiguous — it means a duplicate execution actually happened. Both are now counted per-row and summarized on the Health screen.
