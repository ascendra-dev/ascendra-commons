Payment Link Security — Admin Console

Screen mocks for the payment-link-security module's admin surface. Every read is gated @RequiresAction('payment-link.view') — an ops/security persona, not a tenant-scoped one (a resolution attempt happens before any identity is established).

Why this console exists. A resolve() miss — unknown, guessed, or revoked token — used to return 404 and vanish with zero trace. That's exactly the enumeration/brute-force signal this pattern's own threat model names as a real risk. Token entropy makes guessing computationally infeasible on its own; this and rate-limiting are both defense in depth, not proof it's unnecessary.
